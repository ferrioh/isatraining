# React Bits components

Source: https://github.com/DavidHDev/react-bits (main, retrieved 2026-11-05).
Official TypeScript + CSS sources: BlurText, AnimatedContent, SpotlightCard and StarBorder.
See LICENSE.md for the upstream copyright and license.

Used in the public landing page for heading reveals, scroll entrances, card border highlights and CTA borders. The landing disables heading and image motion when reduced motion is requested; AnimatedContent, SpotlightCard and StarBorder also support reduced motion upstream.

Local adaptation: BlurText uses a span root so it can be placed inside semantic h2 headings.
